\doxysubsection{Detailed Description}
Necessaria all\textquotesingle{}interazione con i file di salvataggio. Ogni volta che si avvia il gioco, l\textquotesingle{}array data verrà caricato con delle struct presenti in un file indice, in modo da poter mostrare le statistiche di ciascun salvataggio. I file di salvataggio avranno un nome del tipo "{}salvataggio0.\+bin"{}, quindi l\textquotesingle{}indice di data verrà usato per la stringa da inserire in fopen(). Si tratta di una rivisitazione dell\textquotesingle{}array dinamico (sostitutivo del vector di C++ dato che in C non è presente) visto a lezione nel modulo di teoria di laP. 

È presente una struct chiamata file\+Format, il cui scopo è quello memorizzare i dati principali del salvataggio (data, p\+Vita, monete, oggetti...), che verranno mostrati quando dal menù verrà selezionata l\textquotesingle{}opzione per caricare/\+eliminare un salvataggio.
